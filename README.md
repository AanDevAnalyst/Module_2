**🚗 G-Cars Data Report — Exploratory Data Analysis (EDA) with Python**

**📘 Project Overview**

This project focuses on performing Exploratory Data Analysis (EDA) on the G-Cars Data Report, a small, publicly available dataset.

Using Python’s Pandas and NumPy, I explored, cleaned, and analyzed the dataset to extract insights and understand relationships between various features.

**🎯 Objectives:**
1. Explore the dataset using Pandas.

2. Calculate basic statistical measures — mean, median, mode, and standard deviation.

3. Analyze correlations between numerical features.

**🧩 Technologies Used**

🐍 Python (v3.11)

📊 Pandas

🔢 NumPy

📓 Jupyter Notebook In VS Code

**📊 Insights & Findings**

From the analysis, I observed that:

🚘 Some features showed strong correlations, indicating possible multicollinearity.

⚙ The dataset was clean with consistent data types and minimal missing values.

📈 Average (mean) values were slightly skewed due to outliers in price and mileage columns.
